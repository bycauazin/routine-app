# Código da interface

[App.jsx](App.jsx) monta as rotas. As [telas autenticadas](features/README.md) usam os componentes de `components/ui` e as cores de [index.css](index.css). Os utilitários e seus testes ficam em `lib`.

O [menu do aplicativo](components/layout/navigation.js) dá acesso aos Relatórios e à revisão histórica.

As [páginas públicas](pages/README.md) apresentam o Routine e dão acesso ao login e à demonstração.
