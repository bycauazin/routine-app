# Página de apresentação

[LandingPage.jsx](../LandingPage.jsx) monta as seções. [public-chrome.jsx](public-chrome.jsx) monta o menu, o rodapé e o botão para entrar. [landing.css](landing.css) define os estilos da apresentação.

O botão [Ver demonstração](../../components/layout/DemoButton.jsx) usa o mesmo fluxo do login. A API é exercitada em [demo.test.js](../../../../routine-back/__tests__/integration/demo.test.js).
