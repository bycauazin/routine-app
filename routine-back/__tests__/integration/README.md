# Testes de integração

[day-week.test.js](day-week.test.js) cobre os blocos do Dia e da Semana, afazeres e listas compartilhadas. O [global-setup.js](global-setup.js) aplica as migrações ao banco dedicado de testes antes de iniciar a suíte.

[reports.test.js](reports.test.js) cobre indicadores, metas e revisão de itens passados.
