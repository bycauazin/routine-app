# Testes da API

`unit/` cobre as regras puras. [integration/](integration/README.md) exercita as rotas e o banco dedicado. Rode `npm run test:unit` ou `npm run test:integration` a partir de [routine-back](../README.md).

Metas e relatórios têm cobertura em [integration/reports.test.js](integration/reports.test.js).
